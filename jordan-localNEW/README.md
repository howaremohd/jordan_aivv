# JordanAI Web Application

A modern, responsive multi-page web platform showcasing AI-powered travel curation across Jordan.

## 📂 Project Structure

- **[`index.html`](file:///C:/Users/user/.gemini/antigravity-ide/scratch/jordan-local/index.html)**: Main landing page featuring the hero banner, multi-criteria search, destination highlights, interactive interest carousel, and interactive floating JordanAI Concierge chatbot.
- **[`discovery.html`](file:///C:/Users/user/.gemini/antigravity-ide/scratch/jordan-local/discovery.html)**: AI Trip Finder experience catalog with real-time interest/adventure filters, sorting by AI match score or price, and detailed match rationale.
- **[`experience-detail.html`](file:///C:/Users/user/.gemini/antigravity-ide/scratch/jordan-local/experience-detail.html)**: Wadi Rum Luxury Star-Gazing Dome experience page with a 4-photo showcase, AI personalization insight, multi-day itinerary, and interactive booking widget with dynamic guest pricing.
- **[`dashboard.html`](file:///C:/Users/user/.gemini/antigravity-ide/scratch/jordan-local/dashboard.html)**: Customer portal with tabbed navigation (Overview, My Profile, Saved Favorites, Previous Trips, Account Settings), digital QR ticket modal, and live profile editing.
- **[`partner-dashboard.html`](file:///C:/Users/user/.gemini/antigravity-ide/scratch/jordan-local/partner-dashboard.html)**: Partner portal for tour operators and experience hosts (Wadi Adventures) featuring interactive Plotly performance analytics, live bookings ledger, package management with the "List New Activity" modal, AI match diagnostic, and traveler messaging inbox.
- **[`login.html`](file:///C:/Users/user/.gemini/antigravity-ide/scratch/jordan-local/login.html)**: Interactive authentication portal featuring a smooth horizontal sliding transition between **Login** and **Sign Up**, ambient beige and Jordanian red glow animations, password strength evaluation, and Google SSO simulation.
